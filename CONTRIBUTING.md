# Como colaborar

1. Crie uma branch com um nome curto e descritivo.
2. Faça alterações pequenas e documentadas.
3. Execute `npm run check` antes do envio.
4. Abra um pull request explicando objetivo, testes e impacto visual.
5. Aguarde a conclusão das verificações automáticas antes do merge.

Nunca inclua tokens, senhas, chaves privadas ou dados pessoais no repositório.

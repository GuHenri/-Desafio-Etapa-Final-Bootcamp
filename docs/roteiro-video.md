# Roteiro da apresentação de 5 minutos

## 0:00-0:35 - Abertura

“Olá, eu sou Gustavo Henrique. Este é o PortfolioHUB, desenvolvido para centralizar meus projetos públicos e demonstrar um processo completo de implantação com GitHub, segurança e apoio de inteligência artificial.”

## 0:35-1:20 - Objetivo e experiência

Mostre a página inicial, a navegação e a adaptação para celular. Explique que a interface usa HTML semântico, CSS responsivo e JavaScript nativo, sem dependências de produção.

## 1:20-2:05 - Integração com GitHub

Abra a seção de projetos. Explique que ela consulta a API pública do usuário `GuHenri`, ordena os repositórios mais recentes e mantém um conteúdo alternativo quando a API não responde.

## 2:05-2:55 - Implantação e colaboração

Mostre o repositório, os arquivos de documentação e os workflows. Explique o fluxo com branches, commits, pull requests, testes automáticos e publicação associada a um commit.

## 2:55-3:45 - Segurança

Apresente a Content Security Policy, a ausência de segredos no frontend, o isolamento de links externos, as permissões mínimas dos workflows e a análise do CodeQL.

## 3:45-4:25 - Apoio do Gemini

Mostre uma captura real do Gemini. Explique qual prompt foi utilizado, o que a resposta sugeriu e qual decisão você tomou após revisar a recomendação.

## 4:25-5:00 - Encerramento

“O resultado é um portfólio leve, rastreável e pronto para evolução. O principal desafio foi equilibrar integração externa, segurança e simplicidade operacional. O código e a documentação estão disponíveis no GitHub.”

# Roteiro de uso ético do Google Gemini

O desafio exige o uso do Gemini como apoio. Execute os prompts abaixo no Gemini e salve capturas das respostas que realmente forem utilizadas. Não apresente como evidência um conteúdo que não foi executado ou revisado por você.

## Prompt 1 - revisão do plano

> Revise este plano de implantação de um portfólio estático integrado à API pública do GitHub. Identifique riscos de implantação, segurança e manutenção. Responda com uma tabela contendo risco, impacto e mitigação.

Cole depois o conteúdo de `docs/implantacao.md`.

## Prompt 2 - segurança

> Analise as seguintes medidas de segurança para um site estático: Content Security Policy, ausência de tokens no frontend, links externos com noopener noreferrer, CodeQL e permissões mínimas no GitHub Actions. Aponte lacunas e priorize correções realistas para um projeto acadêmico.

## Prompt 3 - teste final

> Crie um checklist objetivo para testar um portfólio responsivo em desktop e celular, incluindo navegação por teclado, contraste, carregamento de repositórios do GitHub e comportamento quando a API estiver indisponível.

## Registro sugerido

Para cada interação, anote data, objetivo, trecho aproveitado, decisão humana e captura de tela. Inclua apenas evidências autênticas no PDF final.

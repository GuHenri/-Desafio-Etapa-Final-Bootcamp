Segurança

Proteção incorporada ao projeto

O site evita segredos no cliente, limita origens externas e automatiza análises do código.

01

Conteúdo restrito

Uma política CSP permite somente os recursos necessários para a página.

02

Dependências mínimas

A solução usa a plataforma web nativa e reduz a superfície de atualização.

03

Links externos seguros

Novas abas usam isolamento contra acesso indevido à página de origem.

04

Análise contínua

O CodeQL examina alterações no JavaScript em cada ciclo do repositório.
